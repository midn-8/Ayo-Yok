# Ayo-Yok — Event-Based Social Media Platform

A web-based social networking prototype designed around events, bringing people together through shared activities and experiences. Built with Laravel and React as a collaborative web development project.

## Background

Social media platforms often focus on sharing content, while finding people to connect with through shared interests and activities can require using multiple platforms. Ayo-Yok explores an alternative approach by placing events at the center of social interaction.

The idea behind Ayo-Yok is to create a digital space where event-related activities can become a starting point for social connections.

## Project Overview

Ayo-Yok is an event-based social media prototype developed to explore the design and implementation of a web application that revolves around events and social interaction.

The project uses a full-stack web development approach, combining a Laravel backend with a React-based frontend.

## Core Concept

1. **Event-centered interaction** — Using events as the central concept for organizing social activities.
2. **Social connectivity** — Helping people discover opportunities to connect through shared activities and interests.
3. **Interactive web experience** — Combining frontend components and backend functionality into a cohesive web application.

## Tech Stack

| Component | Technology |
|---|---|
| Backend framework | Laravel 12 |
| Programming language | PHP |
| Frontend library | React |
| Frontend language | JavaScript |
| Styling | Tailwind CSS |
| Build tool | Vite |
| UI animations | Framer Motion |
| HTTP client | Axios |

## Technical Overview

- **Backend:** Laravel handles server-side logic and routing.
- **Frontend:** React supports reusable UI components and interactive interfaces.
- **Styling:** Tailwind CSS supports interface styling.
- **Build process:** Vite manages frontend development and asset bundling.
- **UI interactions:** Framer Motion provides animation capabilities.

## Project Objectives

- Explore an event-based approach to social networking.
- Apply full-stack web development concepts in a practical project.
- Integrate frontend and backend technologies.
- Gain experience with modern web development tools and collaborative software development.

## Project Status

Ayo-Yok is a collaborative web development prototype that explores event-centered social networking and provides a foundation for further development.
