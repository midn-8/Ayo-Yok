# Ayo-Yok — Event-Based Social Media Platform

> A web-based social networking prototype designed around events, bringing people together through shared activities and experiences. Built with Laravel and React as a collaborative web development project.

## Background

Social media platforms often focus on sharing content, while finding people to connect with through shared interests and activities can require using multiple platforms. Ayo-Yok explores an alternative approach by placing events at the center of social interaction.

The idea behind Ayo-Yok is to create a digital space where event-related activities can become a starting point for social connections. By combining web application development with an event-oriented concept, the project explores how technology can support more activity-driven social experiences.

## Project Overview

Ayo-Yok is an event-based social media prototype developed to explore the design and implementation of a web application that revolves around events and social interaction.

The project uses a full-stack web development approach, combining a Laravel backend with a React-based frontend. This architecture provides a foundation for building interactive web interfaces and connecting them with server-side application logic.

## Core Concept

The application is built around three main ideas:

1. **Event-centered interaction** — using events as the central concept for organizing social activities and encouraging interaction.
2. **Social connectivity** — exploring how people can discover opportunities to connect through shared activities and interests.
3. **Interactive web experience** — combining frontend components and backend functionality to deliver a cohesive web application.

## Tech Stack

| Component | Technology |
|---|---|
| Backend framework | Laravel 12 |
| Programming language | PHP |
| Frontend library | React |
| Frontend language | JavaScript |
| Styling | Tailwind CSS |
| Build tool | Vite |
| UI animations | Framer Motion |
| HTTP client | Axios |

## Technical Overview

- **Backend development:** Laravel provides the application framework for handling server-side logic, routing, and integration with application data.
- **Frontend development:** React supports the development of reusable UI components and interactive user interfaces.
- **Styling and responsiveness:** Tailwind CSS supports interface styling through utility classes.
- **Frontend build process:** Vite manages frontend development and production asset bundling.
- **UI interactions:** Framer Motion provides animation capabilities for creating more dynamic interface experiences.

## Project Objectives

- Explore an event-based approach to social networking.
- Apply full-stack web development concepts in a practical project.
- Integrate frontend and backend technologies into a web application.
- Develop experience with modern web development tools and collaborative software development.

## Project Status

Ayo-Yok is a collaborative web development prototype. Its repository provides a foundation for exploring event-centered social networking and further developing its application features and user experience.
